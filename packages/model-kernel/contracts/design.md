# 模型内核目标合同

状态：draft，2026-09-21；[v0.1](v0.1/README.md) 仅实现单实例线程内存事务和有限操作。本设计不归 P1 独占，供应所有模型消费者。

## 输入、输出与状态

拥有已接受模型/关联的版本、历史、提交收据和证据适用性；不拥有需求原文、应用业务数据或代码文件。领域配置定义合法类型/关系/操作与检查支持。只导入 protocols；检查器由编排注入，注入并不证明检查独立。

| 操作 | 输入 → 输出 | 副作用及失败 |
|---|---|---|
| snapshot / resolve | 项目、模型、明确版本/限定元素引用 → 不可变快照/元素 | 只读；未找到或版本不符明确失败 |
| preview | base、ChangeProposal、已声明配置 → 候选、差异、ImpactSet | 无写入；操作不支持或最终结构不合法停止 |
| decide | 候选、报告、策略、actor、范围 → 绑定的决定 | 记录决定；不得用外来成功字符串代替可信执行 |
| apply | 原提案、决定、actor → CommitResult | 比较基准后原子更新指定模型状态/索引/收据；失败不部分提交 |
| impact / applicability | 前后版本、依赖/报告 → affected/current/stale/unknown 及依据 | 不修改历史报告 |
| migration-preview | 旧/新元模型、映射、模型集合 → 迁移候选、损失、阻塞项 | 仅目标设计；不自动执行全项目升级 |

元模型内容与项目模型各自版本化。模型网络使用有方向且带类型的关联；跨模型事务必须显式声明包含哪些模型，目前不承诺跨模型原子事务。没有 migration handler 的扩展返回 unsupported。

## 提交、接受与失效

提案身份、候选哈希、检查范围、规则/工具/前提及许可主体均绑定；提交时重核当前基准。检查先后发生的竞态必须失败或重算，不能用旧许可覆盖新状态。重复同 ID/内容/主体返回原收据，同 ID 改内容 conflict。

模型保存可显式保留未满足义务，不能转成应用交付或业务操作许可。notes 只能增加注记，不允许整状态 callback。原子范围止于设计模型提交；后续文件构建失败保留模型版本与失败记录。

包含边不默认当语义边。利用前后依赖图处理删除及重定向，证据复用要求依赖完整和语义指纹不变。缺失依赖来源返回 unknown；模型根改变不是全部局部证据必然过期的充分理由。现有全计划变化保守 stale 的实现不被本文升级为精准规则级复用。

## 设计验收

A：不同配置的候选走相同提案入口，配置未知不补默认模型。B：同基准冲突只有一个提交、失败回滚、重命名稳定引用、迁移中止保留旧版本、相关失效/无关保留/未知各有反例。C：恢复候选不能直接覆盖意图，来源冲突显式保留。

持久化、跨进程并发、模型网络事务与迁移分别按真实消费者实现；同实例 RLock 的测试不能外推这些能力。
