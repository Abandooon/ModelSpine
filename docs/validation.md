# 工程验收与结果边界

从仓库根运行 `python -B run_tests.py`；只使用 Python 3.10+ 标准库。离线贯穿示例为 `python -B apps/offline.py`，非法阈值反例为 `python -B apps/offline.py --threshold -1`，后者应明确失败并退出 2。

可用 `python -B run_tests.py --package protocols` 单独验收一个包，包名还可选 model-kernel、assurance、generation；`python -B run_tests.py --integration` 验收跨包路径。默认入口在五个隔离子进程中运行四包单元验收和集成验收，单包测试不经 offline CLI 加载其他能力包。

## 有意义的验收

| 边界 | 必须观察的行为 |
|---|---|
| 共享值对象 | 严格字段/类型/版本/哈希；bool 不冒充 int，未知字段不被忽略 |
| 模型提交 | 预览不写状态；权限、旧基准、错误决定和冲突失败；同一提案重试可识别 |
| 影响与证据 | 相关依赖失效、完整无关范围保留、缺失依赖 unknown；原报告不改写 |
| 检查器 | 报告属于实际候选/计划/范围/工具；不支持义务保留残余，伪造或错绑定报告拒绝 |
| 生成与修复 | 构造排除非法值，绕过构造的值仍须终验；改善不得掩盖新增错误、丢失覆盖或变更义务 |
| 模块解耦 | 生产导入符合实际运行依赖；实验/应用装配不得反向进入能力包 |

2026-09-21 历史验收：45 项全部通过，包括 protocols 7、model-kernel 7、assurance 4、generation 7、集成 20；CLI 正常路径退出 0，非法阈值退出 2。对应源码随该轮提交保存，后续修改必须按变更重新验收，不能继承此结果。

首轮切片曾记录 34 项行为测试通过，该数字只覆盖历史版本。新增内核测试用独立检查器证明接口可替换，未宣称实现新的完整领域；报告错绑定、遗漏/重复义务和执行器异常有拒绝反例。

测试入口和实际断言是本仓库可复查的工程依据；来源复用范围见 [provenance.md](provenance.md)。通过这些检查不证明形式化忠实、一般模型演化、任意应用生成或元模型中心方法的比较优势。

## 2026-09-22 公共基础边界复核

本轮完整验收 **69 项全部通过**：protocols 9、model-kernel 11、assurance 5、generation 9、集成 35。四包与集成在隔离子进程中执行；新增适配器可仅加载 protocols 导入。执行命令为 `python -B -I run_tests.py`。

两个 `python -B -I apps/boundary_examples.py --profile ...`（structural-graph / finite-automaton）均退出 0 并提交 revision 1；未知 profile 退出 2。既有 offline CLI 正常退出 0，非法阈值退出 2。完整运行日志、源文件哈希及对应提交在研究工作区本轮任务记录中保留；公开代码与这些可重跑入口随本次 Git 提交保存。

新增 24 项包括来源引用/空字段校验、同实例删除 ID 不复用、impact 比较域、字段控制声明与缺目标优先级，以及 14 项异质配置验收和 1 项适配器隔离导入检查。异质验收包含端点/环、非确定转移、实际输入串拒绝、Unicode 符号、未知义务、虚假依赖完整性、嵌套成员拒绝及其他根隔离。检查或授权失败保持模型不变；全图证据 unknown 和变更后的 stale 均实际观察。

独立审查曾复现嵌套成员被忽略后错误通过，已补拒绝及回归；最终结果包含此修复。自动机 CLI 的 trace 是可编辑模型数据，成功编辑不是保持固定独立需求的证明，详见[边界说明](foundation-boundaries.md)。本轮不增加研究运行或比较结论。

## 支持范围

当前模型仅含有限标量字段和显式依赖。事务只覆盖同一 ModelKernel 实例的内存状态，不覆盖磁盘、跨进程、构建或应用数据。内置 assurance 只支持 integer_range/equals 设计字段义务；显式适配器另解释结构图和有限自动机配置的有限规则，见[支持矩阵](foundation-boundaries.md)。CLI 不执行真实业务批准，也不调用 LLM、外部求解器或付费 API。

既有订单模型是工程夹具；具体金额、币种与角色不成为通用默认。目标行为合同、代码恢复、界面、文件所有权和应用交付尚需对应实现及独立验收。研究比较的条件、真值、失败分母和成本要求见[协议摘要](../studies/lifecycle/protocol.md)。
