# 生命周期比较：公开协议摘要

状态：protocol-only；本文件是公开执行边界摘要，不是已完成实验、预注册记录或完整论文稿。当前无研究运行器、参与者数据或比较结果，元模型中心方法的优势仍待检验。

## 问题与条件

比较代码中心、规格中心、模型辅助、元模型中心四类方法在新建、变更、恢复与交接中的质量和总成本。使用相同任务目标和独立验收；不要求所有方法采用同一内部表示。普通规则工具作为有竞争力的对照，不能只与无检查的弱基线比较。

任务按能力轴选择，包括结构/字段、约束及状态效果、变化传播、来源追踪、外部能力和用户操作。至少用语义不同的模型与任务检查声明范围；不预设某个行业或业务应用作为通用框架的边界。公共基础已有[结构图与有限自动机的工程验收入口](../../docs/foundation-boundaries.md)，有限输入串模拟不替代真实应用任务或独立研究真值；这些样例未登记为比较实验。

P1 关注澄清和任务充分性，P2 关注合同忠实、绑定及相关错误，P3 关注人的理解/操作，P4 关注事实恢复及演化，E 关注跨生命周期净收益。方向实现和替换位置见[框架设计](../../docs/architecture.md)。各方向可以共享输入版本，研究问题和运行集合仍须明确区分。

## 实验装配与隔离

运行器、条件选择、预算、随机种子与分析放在 studies；通过生产包公开接口消费能力，不在生产包植入论文条件开关。替代需求策略、检查器、生成控制、交互投影或恢复方法须显式选择并记录版本，失败不偷偷更换方法。

任务输入、验收真值及检查器分别版本化。开发检查通过不能充当独立验收；共享错误、错误绑定、追踪缺失和不支持片段均需反例。检查器可注入并不证明实验真值独立。

## 每次运行必须固定和记录

- 协议标识/版本、Git 提交、条件/方法版本、模型与工具、输入及验收来源的版本和哈希。
- 明确任务范围、支持/不支持矩阵、允许反馈与修复策略、尝试/时间/费用上限和停止条件。
- 原始输出与加工产物、逐项 satisfied/violated/unknown/not_applicable/error、覆盖范围和残余义务。
- 所有已启动运行及失败、超时、取消和未完成；不只保留成功运行，也不以检查点或相关变体扩充独立样本量。
- 人工主动时间、系统等待、墙钟时间、计算用量/实际费用及一次性建模/适配/学习成本；缺失值说明原因，不补造为零。

运行输出进入独立制品目录或外部制品库，并保留运行清单。公开派生结果与参与者原始数据分开；本代码仓库不保存私人数据。历史代码由 Git 提交定位，运行制品不复制整份源码作为往期版本。

## 验收、分析与停止

独立任务正确性、旧义务保持/新义务满足、误放行/误拒、影响漏检/过度失效、支持覆盖与成本分别报告。真人研究测实际理解和操作，不能拿自动代理或满意度代替非程序员表现。

主运行前确定主要终点、比较方式、独立样本单位、分配与学习效应控制、缺失/退出处理和分析方法；样本量由具体任务与先导数据支持，不在摘要中预填。按预算和预定条件停止，失败成本保留；未出现收益抵消点也是有效结果。
