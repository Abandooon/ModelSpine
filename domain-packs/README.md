# 领域包

保存领域定义、身份规则、约束、示例与资源来源。AUTOSAR 是可选领域包，不得被通用包隐式导入。领域包版本与核心元模型版本分别管理；实例变更不自动升级核心语言。

[既有订单工程夹具 0.1](order-approval/README.md) 包含独立天气实体和未知依赖反例，用于有限实现回归，不指定后续应用试点。业务金额/批准与文件所有权目前是明确标注的合同样例，未实现应用运行时。

[结构图](structural-graph/README.md)和[有限自动机](finite-automaton/README.md)是两类非业务配置，分别检验关系约束与有限行为解释。它们共用标量协议和提交合同，语义由显式适配检查器提供；不代表内核原生支持图/行为语言或任意领域。支持范围与集合依赖限制见[公共基础边界](../docs/foundation-boundaries.md)。
